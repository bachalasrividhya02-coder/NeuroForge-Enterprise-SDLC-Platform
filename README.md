# NeuroForge Enterprise SDLC Platform

## 📌 Project Overview

NeuroForge Enterprise SDLC Platform is a web-based Software Development Life Cycle (SDLC) management platform designed to manage and track different stages of software development in an organized way.

The platform helps manage users, organizations, projects, requirements, tasks, defects, and deployments through a centralized system.

## 🎯 Objectives

- Manage software projects efficiently
- Manage project requirements and tasks
- Track software defects
- Manage deployment information
- Provide REST APIs for different modules
- Store and manage application data using MySQL

## 🚀 Backend Setup

### Prerequisites

Make sure the following are installed:

- Java JDK
- MySQL
- Maven
- Eclipse IDE

### Steps

1. Clone this repository.
2. Open the project in Eclipse.
3. Configure the MySQL database.
4. Configure the required database environment variables.
5. Run the Spring Boot application.
6. The backend server runs on:

`http://localhost:8080`

## 🔐 Configuration

Database configuration is kept outside the GitHub repository for security.

The application requires the following environment variable:

`DB_PASSWORD`

Do not commit database passwords or other sensitive credentials to GitHub.
